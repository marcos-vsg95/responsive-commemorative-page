# Página Comemorativa Responsiva

Uma página web comemorativa criada como um projeto pessoal, desenvolvida para celebrar uma história especial através de um layout romântico, minimalista e responsivo.

O projeto foi desenvolvido com foco em **design, responsividade, organização de código e experiência do usuário**, adaptando a interface para diferentes tamanhos de tela, desde dispositivos móveis até desktops.

---

## ✨ Sobre o Projeto

A página foi criada como um espaço digital para registrar e celebrar momentos especiais de um relacionamento.

O projeto apresenta diferentes seções que contam parte dessa história:

- 🏠 **Início** — apresentação da página e contador do tempo juntos
- ❤️ **Qualidades** — características especiais que admiro
- 📸 **Galeria** — momentos registrados em fotografias
- 💌 **Carta** — uma mensagem especial

A proposta visual combina tons de vinho e rosa, tipografia elegante e fotografias para criar uma experiência delicada e pessoal.

---

## 🎨 Design

O projeto foi pensado para ter uma identidade visual romântica e minimalista, evitando excesso de elementos e efeitos.

Alguns dos principais elementos visuais são:

- Paleta de cores em tons de vinho, rosa e branco
- Tipografia com estilo elegante
- Imagens utilizadas como elementos de destaque
- Cards com sombras e bordas suaves
- Efeitos de transparência e `backdrop-blur`
- Layout adaptável para diferentes tamanhos de tela

A intenção é que a página tenha uma aparência de **álbum digital**, mantendo o foco nas fotografias e na história apresentada.

---

## 📱 Responsividade

A página foi desenvolvida utilizando uma abordagem responsiva, adaptando seus elementos de acordo com o tamanho da tela.

### Mobile

Em dispositivos móveis, o layout se adapta para:

- Melhor aproveitamento da largura disponível
- Conteúdo organizado verticalmente
- Tipografia reduzida proporcionalmente
- Imagens adaptadas à proporção da tela
- Contador reorganizado para facilitar a leitura
- Navegação adaptada para telas menores

### Desktop

Em telas maiores, o layout aproveita o espaço disponível para:

- Exibir os elementos de navegação horizontalmente
- Utilizar imagens maiores
- Organizar a galeria em uma grade
- Aumentar espaçamentos e tamanhos de elementos
- Proporcionar uma experiência visual mais ampla

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica da página
- **Tailwind CSS** — estilização e desenvolvimento responsivo
- **JavaScript** — interações e funcionalidades da página
- **Lucide Icons** — ícones utilizados na interface
- **Google Fonts** — tipografias utilizadas no projeto

### Principais conceitos praticados

- CSS Grid
- Flexbox
- Design responsivo
- Mobile-first
- Breakpoints
- Backgrounds e overlays
- Organização semântica do HTML
- Manipulação do DOM com JavaScript
- Componentização visual através de classes utilitárias
